Privacy policy

Effective 5 September 2026

Space Screens is a YouTube channel and the software that publishes to it. This policy explains what data that software handles.

What the software does

Our publishing tool ("the app") signs in to Google with the channel owner's own account and uses the YouTube Data API to upload videos to the Space Screens channel. It is operated only by the channel owner. It is not offered to, and does not sign in, any other person.

Data we access

The app requests the youtube.upload permission only. It uses that permission to upload video files, titles, descriptions and tags to the owner's channel. It does not read comments, subscriber lists, analytics, contacts, email, or any other Google data.

Data we store

The app stores an OAuth token for the owner's account so it can upload without signing in each day. The token is kept in private, access-controlled storage and is never shared. The app also keeps a local record of which images and videos it has published. No personal data about viewers is collected by the app.

Website

This website is static. It sets no cookies and runs no analytics. Our hosting provider may keep standard server logs (IP address, request time) for security purposes.

YouTube

Watching the channel is governed by Google's privacy policy and YouTube's terms of service. We do not receive personal information about viewers beyond the aggregate statistics YouTube shows every creator.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The channel owner can revoke the app's access at any time at myaccount.google.com/permissions.
