# Music

Drop audio files here and register each one in `manifest.yaml` with a licence.
The pipeline refuses to upload a video whose soundtrack has any track without
a publishable licence, so this folder is the single control point for
Content ID risk. Audio files are git-ignored; commit only the manifest.

Target: 6-10 tracks per genre, 5-15 minutes each, no drums, no vocals,
loudness around -18 LUFS so the mix sits under conversation level.
